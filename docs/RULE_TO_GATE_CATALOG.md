# Rule To Gate Catalog

This catalog is the versioned index from blueprint non-negotiables to their primary enforcement paths.

Update this file in the same review whenever a non-negotiable changes, a gate changes, or a new temporary waiver is introduced.

## Columns

- `Rule ID`: stable identifier used by waivers and CI output
- `Rule`: the governing architectural rule
- `Primary Enforcement`: the gate or mechanism that should fail first
- `Typical Artifact`: the concrete test, analyzer, check, or document family that usually enforces the rule
- `Waiver Scope`: the narrowest scope a waiver is allowed to suppress

## Notes

- A waiver references one `Rule ID` only.
- A foundational architecture change usually updates this catalog and an ADR together.
- A rule may have more than one enforcing artifact; the `Primary Enforcement` column identifies where failure should appear first.
