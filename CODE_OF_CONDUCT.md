# Code of Conduct

This project expects respectful, professional collaboration.

## Expected Behavior

- Be respectful in issues, pull requests, reviews, and discussions.
- Focus criticism on ideas, code, and technical tradeoffs, not people.
- Assume good intent while still being clear and specific.
- Help keep the repo useful for maintainers, contributors, and adopters.

## Unacceptable Behavior

- Harassment, threats, intimidation, or personal attacks.
- Discriminatory or demeaning language.
- Repeated bad-faith argument, derailing, or deliberate disruption.
- Sharing private, sensitive, or security-impacting information irresponsibly.
- Spam, promotional noise, or off-topic abuse of project spaces.

## Scope

This code of conduct applies to repository spaces and project-related communication, including issues, pull requests, review threads, and other maintainer-managed channels tied to this project.

## Reporting

If you experience or witness unacceptable behavior, contact the maintainer through GitHub or another repository-owned contact path if one is published.

For security problems, use [`SECURITY.md`](SECURITY.md) instead.

## Enforcement

Maintainers may edit, hide, lock, remove, or refuse content that violates this code of conduct, and may limit participation when necessary to protect the project and its community.
